# Privacy Changelog

A public record of material changes to Noto's data practices. Every entry includes the date, what changed, the data affected, the provider affected, and the user impact.

---

## 2026-08-25 — Public transparency repository published

- **What changed:** Published the `noto-transparency` GitHub repository documenting Noto's data architecture, data map, AI processing, third-party providers, retention, deletion, export, security, user rights, and international transfers.
- **Data affected:** None (documentation only).
- **Provider affected:** GitHub (documentation hosting only; no user data).
- **User impact:** Users can now inspect how their data is handled in a single public place. No change to data practices.

## 2026-08-25 — AI providers and no-training terms documented

- **What changed:** Formally documented the AI providers (OpenAI, Google, Anthropic) used by Noto's AI features, and marked provider-side training/retention as TO BE VERIFIED pending each provider's current terms.
- **Data affected:** AI inputs (transient).
- **Provider affected:** OpenAI, Google, Anthropic.
- **User impact:** Clearer disclosure; no change to processing. Users are advised to verify provider terms for training/retention.

## 2026-08-20 — Trash auto-purge retention finalized

- **What changed:** Confirmed soft-deleted notes, flashcards, and quiz attempts are purged 30 days after soft-deletion via the scheduled trash auto-purge job.
- **Data affected:** Notes, flashcards, quiz attempts.
- **Provider affected:** Base44.
- **User impact:** Deleted items are restorable for 30 days, then permanently removed.

## 2026-08-12 — AI features require explicit trigger (consent)

- **What changed:** Clarified that all AI features run only on explicit user action; AI inputs are not persisted by Noto.
- **Data affected:** AI inputs.
- **Provider affected:** AI providers.
- **User impact:** No automatic AI processing of user data; users control when AI features run. Consent reaffirmed.

---

*Future material changes to Noto's data practices will be recorded here with the date, the change, the data and providers affected, and the user impact.*
