# Noto Transparency

**Noto doesn't ask users to blindly trust its privacy practices. It shows them how their data is handled.**

This repository is a public, plain-language documentation of how **Noto** — a student productivity app (notes, calendar, tasks, mind maps, focus timer, flashcards, quizzes, revision sheets, and AI study tools) — collects, stores, processes, shares, protects, retains, and deletes user data.

> ⚠️ This repository contains **documentation and transparency information only**. It does **not** contain Noto's application source code, user data, credentials, API keys, or any secrets.

## About this documentation

- Written primarily for **Noto users**, not developers.
- Documents the infrastructure that **actually exists** in Noto.
- Where a fact could not be verified from Noto's own systems, it is explicitly marked **TO BE VERIFIED**.
- Noto never makes unverified privacy, security, retention, encryption, or AI-training claims in this repository.

## In-app transparency

Noto also surfaces much of this information inside the app:
- A **Privacy Nutrition Label** (in-app dashboard)
- **Contextual AI data-use badges** shown at the point an AI feature is used
- A country-adapted **privacy policy** and rights panel

This repository is the public, inspectable mirror of that in-app transparency.
